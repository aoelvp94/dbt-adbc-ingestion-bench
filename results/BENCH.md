# Benchmark results

Generated by `python -m bench.report` from the harness JSON. Every number below was measured on the machine described in [Environment](#environment); nothing is projected unless it says so.

* Runs: 2026-11-10T10:54:59+04:00 -> n/a; 2026-11-10T11:24:01+04:00 -> 2026-11-10T12:26:27+04:00
* Rounds: 3 timed rounds per cell (median shown) + 1 memory round; timeout 600 s per run.
* Rows = orders + customers (customers = orders / 20). Times include reading the input file and creating the table, exclude Python imports and dataset generation.
* `Peak RSS` = process high-water mark (ru_maxrss); `+delta` = growth during the load. `Py heap peak` = tracemalloc (Python objects only). `Arrow pool` = pyarrow allocator max. Memory columns come from separate runs (see README, Methodology).
